# Daily Fraud, Risk & Data Analytics

> **One problem every day. One year of continuous learning.**

This repository is my **365-day coding and analytics journey** focused on **Fraud Detection, Risk Analytics, Credit Risk, SQL, Python, Pandas, Statistics, Machine Learning, and Data Analysis**.

Instead of using only one dataset, I will practice with **different datasets from multiple domains**. These may include financial transactions, fraud detection, credit risk, customer behavior, e-commerce, banking, insurance, healthcare, marketing, and other real-world analytical problems.

The objective is to develop the ability to work with unfamiliar data, understand a business problem, clean and analyze datasets, write efficient code, extract insights, engineer features, and build predictive models.
